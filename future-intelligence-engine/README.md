# Future Intelligence Engine

Проект для построения системы предсказаний и аналитики на основе событий.

## Структура проекта

- `agents/` — логика агентов и рабочих процессов
- `data/` — источники данных, схемы, загрузчики
- `events/` — события, очереди, обработчики
- `prediction/` — модели, прогнозы, ML/статистика
- `dashboard/` — визуализация, веб-интерфейс, отчёты
- `utils/` — вспомогательные функции и общие утилиты
- `config/` — конфигурационные файлы и настройки окружений
- `tests/` — тесты

## Запуск

```bash
python3 main.py
```
